# PANEL DE CONTROL - Plataforma Unificada

Sistema de gestión integrador desplegado mediante GitHub Pages. Consolida las plataformas de seguimiento territorial y registro de formularios en una sola interfaz adaptable para dispositivos móviles y de escritorio.

## 🚀 Aplicaciones Integradas

1. **BACHEO-2026**: [Acceso Directo](https://gabrielrgr-wq.github.io/BACHEO-2026/)
2. **FORMULARIOS al 2026**: [Acceso Directo](https://gabrielrgr-wq.github.io/app1/)

## 🛠️ Tecnologías Utilizadas

* HTML5 / CSS3 (Diseño responsivo móvil)
* JavaScript Vanilla (Navegación entre vistas)
* Font Awesome & Google Fonts (Interfaz moderna)
* GitHub Pages (Hosting)

## 📱 Características

* **Mobile-First**: Menú superior optimizado para pantallas táctiles.
* **Consolidación Iframe**: Navegación fluida entre herramientas sin recargar la página.
* **Enlace Externo Dinámico**: Permite abrir el módulo activo directamente en una pestaña independiente.
